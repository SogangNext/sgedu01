Section 02

AI 도구 라인업

Text-to-Text
💬 ChatGPT · Claude
자기소개서 초안 생성, 프로젝트 상세 설명 구성, 직무 핵심 키워드 매핑 및 면접 예상 질문 대응에 활용합니다.
자소서 초안 기술 키워드 문맥 교정
Presentation
🎨 Gamma
텍스트 한 줄로 전문가급 레이아웃의 발표 자료를 자동화합니다. 포트폴리오 슬라이드 및 프로젝트 요약서 제작에 최적입니다.
발표 자료 레이아웃 자동화 PPT 생성
Visual Art
🖼️ Midjourney · DALL-E
프로젝트의 시각적 완성도를 높이는 컨셉 아트, 썸네일, 커버 비주얼을 전문가 수준으로 디자인합니다.
컨셉 아트 썸네일 비주얼 고도화
Vocal & Video
🎬 Runway · ElevenLabs
게임 시연 영상의 고도화 작업 및 발표용 나레이션 생성을 통해 멀티미디어적 몰입감을 극대화합니다.
영상 편집 AI 나레이션 영상 제작
Code & Docs
💻 GitHub Copilot · Notion
코드 최적화와 자동 README 작성을 통해 기술적 완성도를 증명하고, 체계적인 문서 라이브러리를 구축합니다.
README 자동화 코드 최적화 문서 정리
Web Platform
🌐 Framer · Webflow AI
노코딩 AI 툴로 고성능 웹 포트폴리오를 제작하여, URL 하나로 언제든 접근 가능한 나만의 채널을 배포합니다.
웹 사이트 도메인 배포 URL 공유
Section 03

8주 완성 커리큘럼

1
Orientation
AI 시대의 포트폴리오 전략
프롬프트 엔지니어링의 기본 원리를 실습하고, 자신의 강점과 목표 직무를 정리하는 '나의 직무 프로파일 카드' 작성.
직무 프로파일 카드 AI 계정 세팅
2
Discovery
프로젝트 소재 발굴 및 키워드 매핑
STAR 기법을 활용하여 과거 프로젝트를 분석하고, 채용 시장의 핵심 키워드를 AI와 대화하며 추출 및 연결.
프로젝트 분석서 직무 키워드 맵
3
Writing
AI 자기소개서 및 면접 답변 설계
Claude를 활용한 4대 핵심 문항 초안 작성. AI 특유의 말투를 제거하고 나만의 보이스를 입히는 '인간화 편집' 가이드.
자소서 완성본 면접 10문선
4
Visualization
포트폴리오 비주얼 브랜딩 설계
Midjourney 등을 활용한 프로젝트 썸네일 및 커버 제작. 면접관의 시선을 머물게 하는 고품격 비주얼 테마 설정.
커버 이미지 3종 비주얼 가이드라인
5
Creation
Gamma로 완성하는 프리미엄 슬라이드
구조화된 텍스트를 Gamma AI에 주입하여 10페이지 분량의 포트폴리오 슬라이드 자동 생성 및 실전 커스터마이징.
포트폴리오 PPT 발표 자료
6
Optimization
GitHub & README.md AI 자동화
개발자의 얼굴인 GitHub 저장소를 AI로 최적화. 기술 스택, 시연 영상, 아키텍처 다이어그램 자동화 구성 실습.
README.md 완성 GitHub 프로필 팩
7
Practice
AI 모의 면접 및 피드백 훈련
자신의 포트폴리오를 기반으로 AI 면접관과 실시간 시뮬레이션. 답변의 논리성과 직무 적합성을 AI 데이터로 점검.
면접 피드백 리포트 질문 대응 DB
8
Final Presentation
최종 성과 발표 및 리뷰
완성된 포트폴리오를 성과공유 플랫폼에 등록하고, 동료 평가(Peer Review) 및 전문가 최종 피드백을 수렴.
최종 포트폴리오 PDF 수료 인증
Section 04

세부 일정표

주차 단계 주요 교육 내용 주요 산출물
1~3주차 Planning 직무 분석, 소재 발굴, 자기소개서 완성 직무 카드, 자소서 초안
4~5주차 Design 비주얼 생성, 슬라이드 레이아웃, 포트폴리오 제작 슬라이드 PPT, 비주얼 셋
6~7주차 Refine GitHub README 최적화, AI 모의면접 시뮬레이션 README.md, 면접 리포트
8주차 Finish 최종 포트폴리오 완성 및 성과 발표회 최종 결과물 PDF
